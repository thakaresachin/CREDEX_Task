# Credex — AI Spend Audit Platform

Credex is a full-stack AI cost optimization platform that helps startups and teams analyze their AI tooling expenses and discover potential savings opportunities.

The platform allows users to:

- Add AI tools they currently pay for
- Analyze monthly AI spending
- Generate optimization recommendations
- View estimated monthly & annual savings
- Generate AI-powered audit summaries
- Share audit reports publicly

---

# Tech Stack

## Frontend
- React.js
- Vite
- Tailwind CSS
- React Router DOM
- Lucide React

## Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Groq AI API
